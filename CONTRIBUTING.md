# Contributing to HotaruWeb

We welcome contributions to the official Hotaru web portal and documentation manual.

## Development setup

1. Clone the repository:
   ```bash
   git clone https://github.com/HotaruProject/HotaruWeb.git
   cd HotaruWeb
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Verify production build:
   ```bash
   npm run build
   ```

## Contribution guidelines

- Maintain the dark monochrome aesthetic.
- Preserve responsive layout across mobile and desktop breakpoints.
- Hotaru enforces a strict policy of zero comments in code.
