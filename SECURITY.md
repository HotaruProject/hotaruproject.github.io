# Security policy

## Supported versions

Security updates are provided exclusively for the latest commit on the `main` branch.

| Version / Branch | Supported |
|---|---|
| `main` | Yes |
| Older commits | No |

## Reporting a vulnerability

Do not report potential security vulnerabilities in public GitHub issues or discussions.

Use GitHub Private Vulnerability Reporting to submit security findings:

[Submit a Security Advisory](https://github.com/HotaruProject/HotaruWeb/security/advisories/new)

### What to include

- Description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or proof of concept.
- Affected browser or device environment details.

## Response timeline

- Acknowledgment: within 48 hours.
- Fix deployment: released directly to production upon verification.
